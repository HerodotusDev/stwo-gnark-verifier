# Stwo Gnark Verifier

A Go-based implementation of a Zero-Knowledge verifier for the **Stwo** proving system, built using the **Gnark** library.

This project implements a SNARK circuit designed to verify Cairo STARK proofs generated by **Stwo Cairo** (Starknet's next-generation Circle STARK prover, adapted to Cairo ZKVM AIR).
By wrapping the Stwo Circle STARKs verifier logic into a Groth16 or Plonk circuit, it enables efficient on-chain verification of Cairo ZKVM execution traces.

---

## 🌟 About

Directly verifying Circle STARK proofs on-chain can be computationally expensive. This repository allows developers to:

* **Recursive Proofs:** Wrap a Stwo STARK proof into a constant-size SNARK proof.
* **EVM Compatibility:** Enable low-cost verification of large Cairo execution traces on Ethereum and other EVM chains.

---

## 🏗 Architecture

* `m31/`: Core  and  field arithmetic implementation.
* `circle/`: Circle curve operations, domain definitions, and vanishing polynomials.
* `fri/`: Implementation of the FRI protocol layers and Merkle verifier.
* `components/cairo_components/`: Constraint evaluation logic for Cairo-specific opcodes and builtins.
* `variables/`: Data structures for proof deserialization and circuit variables.

---

## 🛠 Usage

### Running the Main Verifier

The entry point `main.go` demonstrates the full pipeline: loading a sample proof, compiling the circuit, performing a setup, generating a witness, and finally producing and verifying a Groth16 proof.

```bash
go run main.go

```

### Testing

The project contains extensive unit tests for individual arithmetic components, Cairo opcodes, and the full verification flow.

*Note: Ensure valid JSON proof fixtures exist in the `test_data` directory.*

```bash
# Run all tests
go test ./...

# Run tests with the short flag (recommended for local development)
go test -short ./...

```

## Relevant Projects

* **[Stwo](https://github.com/starkware-libs/stwo)** — **A next-generation STARK prover.**
* The primary Rust implementation of the Circle STARK protocol.


* **[Stwo-Cairo](https://github.com/starkware-libs/stwo-cairo)** — **A tool to prove Cairo ZKVM programs using the Stwo prover.**
* An adapter designed to compile and prove execution traces of the Cairo ZKVM using the Stwo backend.


* **[Gnark](https://github.com/Consensys/gnark)** — **A fast ZK-SNARK library that offers a high-level API to design circuits.**
* The foundational Go-based framework used to implement this verifier's arithmetic circuits.
