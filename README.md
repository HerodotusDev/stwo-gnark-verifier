# Stwo Gnark Verifier

A Go-based implementation of a Zero-Knowledge verifier for the **Stwo** proving system, built using the **Gnark** library.

This project implements a circuit that verifies STARK proofs generated by Stwo (Starknet's new Circle STARK prover) over the M31 field. By wrapping the STARK verifier in a Groth16/Plonk SNARK circuit, it enables efficient on-chain verification of Cairo execution traces.

## Usage

### Running the Main Verifier

The entry point `main.go` loads a sample Stwo proof (from `test_data/`), compiles the verifier circuit, performs a Groth16 setup, creates a witness, generates a proof, and verifies it.

```bash
go run main.go
```

*Note: Ensure valid JSON proof fixtures exist in the `test_data` directory.*

### Testing

The project contains extensive unit tests for individual components, arithmetic fields, and the full verification flow.

**Run all tests:**

```bash
go test ./...
```

## Project Structure

```text
├── blake2s/        # Blake2s hash implementation for the channel
├── channel/        # Fiat-Shamir transcript channel logic
├── circle/         # Circle curve arithmetic and domain logic
├── components/     # Cairo AIR components (Opcodes & Builtins)
│   └── cairo_components/
│       └── subroutines/  # Low-level constraint evaluations
├── fri/            # FRI protocol verification logic
├── m31/            # M31 and QM31 field implementations
├── variables/      # Data structures for Proofs, Claims, and Deserialization
├── verifier/       # Core Commitment Scheme and Verifier Chip
└── main.go         # Entry point for full proof cycle
```
